# Punnagai Dental Care | புன்னகை பல் மருத்துவமனை

A bilingual (English & Tamil) responsive dental clinic website for Chennai businesses, featuring seamless online and WhatsApp appointment booking, full treatment catalog, clinical timing schedules, and an interactive Google Maps location preview.

---

## 🌟 Key Features

- **🌐 Bilingual Toggle**: Instant 1-click toggle between English and தமிழ் without page reloads.
- **📱 WhatsApp Appointment Booking**: Direct integration with WhatsApp (`+91 8838340480`) prefilling the patient's name, phone, and selected dental service.
- **🦷 Comprehensive Service Catalog**: Painless Root Canal (RCT), Laser Teeth Whitening, Dental Implants, Clear Aligners & Braces, Pediatric (Kids) Dentistry, and Zirconia Crowns & Bridges.
- **📍 Clinic Location & Working Hours**: Full address in T. Nagar, Chennai, complete with embedded Google Maps and timing details.
- **⚡ Ultra-lightweight & Fast**: Pure static HTML5, CSS3, and modern Vanilla JS. No build tools or large dependencies required.
- **📱 Mobile & Dark Mode Friendly**: Responsive typography and grid layouts that fit any screen size seamlessly.

## 🚀 One-Click Deployment

### Netlify
- Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop) for instant deployment.
- Or link this GitHub repository with publish directory set to `.`.

### Vercel
- Import this repository on [Vercel](https://vercel.com) as a static site.

### GitHub Pages
1. Go to repository **Settings** -> **Pages**.
2. Select `Deploy from a branch` -> choose `main` / `root`.
3. Click **Save**. Your site will be live at `https://sudeshpranav.github.io/Punnagai-Dental-Care/`!
